## 🔄 Sinkronisasi Penuh Antar-Halaman (Seamless Persistence)

Walaupun setiap menu kini berada di halaman terpisah, **seluruh fitur penting tetap tersinkronisasi 100%**:
- **Keranjang Belanja (*Cart Drawer*)**: Menambahkan produk di satu halaman (misalnya `collection.html`) akan langsung muncul di keranjang halaman lain (seperti `stories.html` atau `index.html`) tanpa hilang, berkat sinkronisasi otomatis `localStorage`.
- **Mata Uang (*Currency Engine*)**: Mengubah mata uang ke IDR (Rp), EUR (€), atau GBP (£) akan otomatis konsisten di seluruh halaman yang dibuka.
- **Pencarian Cepat (*Search Modal*)**: Bekerja dari halaman manapun dengan saran kata kunci otomatis.
- **Notifikasi Toast Melayang**: Muncul di semua halaman saat produk dimasukkan ke keranjang.
